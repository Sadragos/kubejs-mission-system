Was steht in diesen Dateien:

- break.csv Blöcke müssen abgebaut werden
- kills.csv Monster müssen gekillt werdne
- place.csv Blöcke müssen platziert werden
- submit.csv Gegenstände werden abgegeben / eingereicht

Welche Spalte ist was?

| Spaltenüberschrift | Beschreibung                                                            |
|--------------------|-------------------------------------------------------------------------|
| item               | Item- oder Block-ID, die für den Quest relevant ist                     |
| name               | Der Name, des Items / Blocks / Mobs, der im Quest angezeigt werden soll |
| amount             | Die Anzahl, des Items / Blocks / Mobs, die für den Quest nötig sind     |
| coin_base          | Garantierte Belohnung an Coins                                          |
| coin_bonus         | Maximale Anzahl an Coins, die zu coin_base dazukommen                   |
| mob                | ID des mobs, dass relevant ist für den Quest                            |
| icon               | Das Icons, dass für den Quest angezeigt werden soll                     |
